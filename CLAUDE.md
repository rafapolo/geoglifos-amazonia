# geoglifos-amazonia

- Tudo neste projeto é em português do Brasil: site, README, documentação, comentários, mensagens dos scripts, nomes novos de variáveis/campos e mensagens de commit (no formato convencional, com o tipo em inglês: `feat: adiciona camada de contornos`).
- Dados de James Q. Jacobs são "all rights reserved", mas ele autorizou a publicação (por e-mail, registrado em 2026-11-04; ver `sources.md`): os brutos ficam em `data/raw/` (fora do git) e o convertido, sem áreas de busca, topografia e alinhamentos, vai para `docs/data/jacobs/`, sempre com crédito.
- Só publicar dados de fontes com licença aberta e registrar cada fonte em `sources.md`. Exceção decidida em 2026-11-03: as fotos do app de R. Walker são publicadas reduzidas e com crédito em cada uma (`docs/data/fotos/`).
- Pipeline: `script/sync.sh` → `script/extract_nature2026.py` → `script/convert.py`; fotos: `script/extrai_walker_marcadores.py` → `script/sync_walker.py`; LiDAR aberto (EBA): `script/zipremoto.py` → `script/lidar_eba.py` (no beelink, em `~/geoglifos-lidar/`), saída em `docs/data/lidar/`; figuras da Nature: `script/figuras_nature.py`; desmatamento do tour (PRODES): `script/prodes.py`; o site estático fica em `docs/`; `bun run build` (`script/build.js`) gera `dist/` minificado, publicado no GitHub Pages pelo workflow `.github/workflows/deploy.yml` a cada push na main. O endereço principal é https://xn--2dk.xyz/dataviz/geoglifos-amazonia/: `script/publica_xyz.sh` faz o build, copia `dist/` para `~/Projetos/xyz/dataviz/geoglifos-amazonia/` e faz commit e push no repositório xyz.
